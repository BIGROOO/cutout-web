# Cutout 浏览器版

[打开网站](https://bigrooo.github.io/cutout-web/)

公开仓库仅保存已编译的静态网站文件；完整项目单独保存。

支持文件夹批量抠图、透明 PNG 预览、单张下载和 ZIP。图片只在访问者浏览器内处理，不上传服务器。支持极速、快速、高质量、人像模式。首次下载所选模型约 176 / 181 / 930 / 930 MB，后续优先读取浏览器缓存。单张图片导入后自动开始，批量图片仍需点击开始。建议使用电脑端新版 Chrome 或 Edge。处理速度取决于设备，不保证所有设备每张均少于 10 秒；复杂毛发、阴影、透明物体可能需要更高质量模型。

每批最多 200 张，单张 25 MiB / 4000 万像素；结果总量 256 MiB 上限，建议大图分批。清空或刷新页面会丢弃图片和结果，浏览器缓存只保存模型。

第三方软件及模型许可见 site/licenses。模型来自 rembg v0.0.0 发布附件；BiRefNet 使用原 FP32 权重，将展开的可变形卷积融合为原生算子以降低内存开销，输入仍为 1024。发布流程校验 SHA-256。高质量和人像模型由同账号下 cutout-model-general / cutout-model-portrait Pages 提供。
